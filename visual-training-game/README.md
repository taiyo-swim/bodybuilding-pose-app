# 視覚トレーニングゲーム（visual_training_game）

一瞬だけ表示されるガボールパッチの傾きを、リズムに乗せて判別し続けるゲーム。

**仕様と判断基準は [`CLAUDE.md`](./CLAUDE.md) が正。** 迷ったらまずそちらを読むこと。
実装が先行して仕様が後追いにならないよう、決定事項は会話ではなく `CLAUDE.md` に書く。

---

## セットアップ

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs   # drift の生成コード
flutter test
tool/compile_shaders.sh                                     # シェーダーのコンパイル検証
flutter run                                                 # 実機推奨
```

`*.g.dart` は `.gitignore` 済み。クローン直後は必ず `build_runner` を回すこと。

## 着手していない領域と、その理由

仕様書セクション0の未決事項に触れるため、**推測で埋めずに止めている**。

| 項目 | 状態 |
|---|---|
| B: 閾値推定の方法と試行数 | 週次コンディション測定モードは未着手。`session.thresholdContrast` は null のまま |
| C: 初回キャリブレーション手順 | オンボーディング未着手。視距離は暫定40cm固定で動く |
| D: 計測イベント（行動ログ） | 未着手。訓練ログ（`trial`）とは別物 |
| E: アカウント引き継ぎ | 未着手。Firebase は Phase 2 |
| F: リーグ人数・曲数・課金 | 未着手。Phase 3 |

未決事項A（刺激の物理サイズ）は暫定方針「ppi補正のみ・視距離40cm固定」で実装済み。
λ の一次表現は**視角（分）**であり、論理px への換算は `ViewingGeometry` 1箇所に閉じている。

## 表現の制約（仕様書 10）

アプリ名・説明文・スクリーンショット・アプリ内文言のいずれにも
**「視力回復」「視力が上がる」を入れない。** 非医療機器において明確にNGとされる表現。
