# BGM トラック配置ディレクトリ

仕様書 2.1 に従い、1曲につき 1 ディレクトリを作る。

```
assets/audio/tracks/{track_id}/
  loop.wav            ステム分割できない場合の1枚ミックス
  stem_drums.wav      可能ならステムを分ける（コンボでレイヤーを増減させるため）
  stem_bass.wav
  stem_lead.wav
  meta.json           必須
```

## 制約（仕様書 2.1）

- **BPM は 120 固定**。曲ごとに BPM を変えない
- 曲は**ループ可能な素材**として扱う。3分のセッションに合わせて尺を作らない
- `meta.json` は必須。ストア審査や後日の問い合わせで出所の説明を求められた際、
  これがないと詰む。**どのプランで生成したか**を必ず記録する

## meta.json

`meta.template.json` をコピーして使う。
