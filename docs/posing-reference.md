# ボディビル フリーポーズ 実装リファレンス

このアプリが生成すべき「フリーポーズルーティン」とは何かを、競技規則と
ポージング指導の一次情報から整理したもの。`routine_generator.py` と
`viewer3d.ts` の実装判断はこの文書を根拠にする。

動画は解析していない（映像を処理する手段がない）ため、
**各ポーズの正確な関節角度は本文書では決まらない** → 「未確定事項」参照。

---

## 1. フリーポーズとは

- **規定ポーズ（比較ラウンド）とは別の、選手が自分で振り付ける自由演技**
- 長さは団体・大会により **60〜120秒**（90秒が多い）。音楽は選手が持ち込む
- 審査対象は「ポーズの数」ではなく
  **見せ方・流れ(flow)・独創性・音楽との一体感(musicality)・ステージ映え**
- ボディビルが最も**パフォーマンスアート**に近づく場面。
  表情・カリスマ・確信を持った所作・コントロールされた動きが評価される

> **重要な前提（ここを間違えると全部外れる）:**
> フリーポーズは**規定7ポーズの朗読ではない。**
> 規定ポーズはあくまで語彙の一部で、非規定のフリースタイルポーズ、
> 選手固有のシグネチャーポーズ、そして**ポーズ間の動きそのもの**で構成される。
> Kai Greene はショットだけでなく**トランジションまで絵に描いて**設計しており、
> それが「他の選手が板のように見える」差を生んでいる。

---

## 2. ポーズ語彙

### 2-1. 規定ポーズ（IFBB メンズボディビル / 公式順序）

| # | ポーズ | 向き |
|---|--------|------|
| 1 | フロントダブルバイセップス | 正面 |
| 2 | フロントラットスプレッド | 正面 |
| 3 | サイドチェスト | 側面 |
| 4 | リアダブルバイセップス | 背面 |
| 5 | リアラットスプレッド | 背面 |
| 6 | サイドトライセップス | 側面 |
| 7 | アブドミナルアンドサイ | 正面 |

団体によりモストマスキュラーを8番目に加える。

### 2-2. 非規定（フリースタイル）ポーズ

フリーポーズの独創性はここで出る。

| ポーズ | 形 | 見せる部位 |
|--------|-----|-----------|
| **モストマスキュラー / クラブ** | やや前傾、胸を突き上げ「樽を抱くように」締める。肩を前へ丸め僧帽筋を持ち上げる。手は前で組む（片手で反対の手首を掴む／両拳を押し合わせる／手のひらを合わせ指を下へ） | 僧帽筋・三角筋・大胸筋・腕 |
| **ビクトリーポーズ** | 両腕を頭上にV字、**拳を握る** | 全身のシルエット・Vテーパー |
| **オーバーヘッドアブス** | 両腕（または片腕）を頭上へ、肘をやや外、手を後頭部で組むか重ねる。肘を少し前に出して広背筋を広げ、同時に腹筋を丸める | 腹筋・Vテーパー・広背筋 |
| **サイドアブス／腹斜筋** | 頭上に腕を上げ、腹筋を左右に振って見せる | 腹斜筋・肋間筋 |
| **アーチャーポーズ** | 弓を引く形。**片腕を曲げ、もう一方を伸ばす** | 前鋸筋・背中・腕（独特の角度） |
| **マンティスポーズ** | 片腕を曲げて上腕二頭筋、もう一方を体の前を横切るように下へ伸ばす | 腕・胸 |
| **バキューム** | 腹を引き込んで凹ませ、胸郭を広げる | ウエストの細さと肩幅の対比 |
| **ザ・ニール（膝つき）** | **横向きに膝をつく。** 正面向き／背面向きどちらも可。脚が主役だが体幹と上半身も見せる | 大腿・全身 |
| **クアッドストンプ** | 脚を機械的に持ち上げて踏み下ろし、全身を締める。その後**両手で大腿を指す** | 大腿四頭筋 |
| **ハムストリングポーズ** | 脚の後面の分離を見せる（Tom Platz が有名に） | ハムストリングス |
| **ツイスティングバックポーズ** | 捻りながら最後はフロントリラックスで終わる | 背中→正面への転換を兼ねる |

最上位ではアクロバット（Kai Greene の前転・逆立ちからの開脚など）も入るが、
本アプリのスコープ外とする。

### 2-3. クォーターターン（振り付けの基礎語彙）

`フロントリラックス → 右へ90° → 背面 → 右へ90°` で正面に戻る。
90°ずつ、頭は正面のまま、足は床に着けたまま、脚は伸ばすがロックしない。
フリーポーズでも**正面と背面をつなぐ移動の基本形**として使う。

## 3. 各規定ポーズの形（脚・足を含む）

現実装は**全ポーズで脚を一切指定していない**。脚はボディビルのポーズの
重要な構成要素なので必ず反映する。

### フロントダブルバイセップス（正面）
- **脚**: 肩幅、つま先をやや外へ開き「V」字。膝を軽く外へ向け、
  膝をロックせずに大腿四頭筋を前へ押し出す。内側広筋を収縮。ふくらはぎも締める
- **腕**: 両腕を肩の高さで水平に、肘を曲げて上腕二頭筋を収縮。**握り拳**

### フロントラットスプレッド（正面）
- **脚**: 肩幅、つま先をやや外へ。脚を締めて大腿四頭筋と臀部の分離を出す
- **手**: 腰骨より少し上に置き、**親指と人差し指で脇腹をつまむ**
- **胴**: 息を強く吐いて体幹を締め、胸を張り、肩甲骨を引き下げて後ろへ、やや後傾。
  肘を体の前方へ押し出すと肩甲骨が広がり広背筋が最大に広がる

### サイドチェスト（側面）
- **脚**: **後ろ脚は伸ばす／前脚は曲げる。前足のかかとを上げてつま先立ち。**
  両脚を寄せて密着させ、前脚・後ろ脚のスイープを出す
- **腕**: 客席側の腕を曲げて上腕二頭筋を収縮させ、**反対の手でその手首を下へ押す**
- **胴**: 肺に空気を入れて胸郭を持ち上げ、肩を後ろへ引く

### リアダブルバイセップス（背面）
- **脚**: 片足の裏に体重を乗せ、**もう一方の脚を後方かつ外側へ 25〜38cm 引く**。
  膝はやや外向きでほんの少し曲げる。足で床を掻くようにハムストリングスを収縮。
  ふくらはぎとハムストリングスを締め、臀部を強く締める
- **腕**: 両腕を横に出し、**床と平行かやや上**。肘から肘まで一直線。肩甲骨は寄せすぎない

### リアラットスプレッド（背面）
- **脚**: **スタガードスタンス（前後にずらす）で後ろ脚のかかとを上げる**。
  ふくらはぎ・ハムストリングス・臀部を締める
- **手**: 親指と人差し指で脇腹をつまむ
- **胴**: 肩甲骨を引き下げて後ろへ、**肘を背中の後ろで寄せる**

### サイドトライセップス（側面）
- **脚**: **サイドチェストとほぼ同じ。前脚を曲げて前足のかかとを上げる。** 後ろ脚は接地
- **腕**: **後ろ側の腕を背中の後ろに回し、審査員側の腕の手首を掴む。**
  その腕を体に強く引き付け、審査員側の腕は**伸ばしてロック**し上腕三頭筋を出す

### アブドミナルアンドサイ（正面）
- **脚**: **片脚をやや前へ伸ばし、大腿四頭筋とふくらはぎを収縮**
- **腕**: **両手を頭の後ろに、指を組む**
- **胴**: 息を全部吐き切って腹筋を丸めるように強く収縮。広背筋は広げてVテーパーを維持

## 4. 向きの流れの原則

規定7ポーズの向きの並びは
**正面・正面 → 側面 → 背面・背面 → 側面 → 正面** で、
一方向に回って戻る。180°反転は含まれない。

これは**フリーポーズの雛形ではない**が、次の原則の裏付けになる。

> **原則: 体の向きの変更は「意図」を伴うこと。**
> - 正面↔背面の移動は、原則としてクォーターターンで**側面を経由**する
> - **180°ターンそれ自体は禁じ手ではない。** 音のキメ（ドロップ・アクセント）に
>   合わせて打つ転換は演技上の武器になる。
>   実際、側面ポーズ間の転換では**180°回って左右の脚を入れ替える**定番の足さばきがある
> - 禁じ手なのは**動機のない反転の連発**。
>   数秒ごとに正面↔背面を往復する振り付けは演技として成立しない

## 5. ルーティンの構成（90秒想定）

| 区間 | 長さ | 内容 |
|------|------|------|
| 入場の「間」 | 2〜3秒 | **すぐポーズしない。音楽を先に呼吸させる** |
| オープニング | 5〜8秒 | 自分の**最強の正面ポーズ**を**最初の大きなドロップに合わせて打つ** |
| 正面ブロック | 15〜20秒 | 正面〜側面のポーズ 2〜3個 |
| 背面ブロック | 15〜20秒 | リアダブルバイセップス＋リアラットスプレッド＋背面のつなぎ |
| クライマックス／最終ポーズ | — | **一番いい形**で締める |

上記は典型例。フリースタイルポーズやシグネチャーポーズをどこに差し込むかは自由で、
そこが独創性の評価対象になる。

### タイミングの原則

- **決めポーズ（money shot）は 2〜3秒しっかり止める**
- **トランジションはホールドより速い**
- **2〜4ポーズを1つの「フレーズ」**として扱い、音楽のフレーズ構造に合わせる。
  単発ポーズの羅列にしない
- 音の要所（**ドロップ・クレッシェンド・無音**）を先に特定し、
  そこに**一番いいポーズを割り当てる**

> 実装上の含意: 90秒で現実的なポーズ数は **およそ8〜12個**。
> 3.75秒等間隔で24個は約2.4倍多すぎる。

---

## 6. トランジション（ここが演技の本体）

- **足さばきが本体。** 左右へ滑らかに移動する
- 側面ポーズ間の転換例:
  右サイドのポーズ（右足で床を踏み、左脚は後ろでかかとを上げる）から
  **180°回って左右の脚の位置を入れ替える**
- **「解放すべきものだけを解放する」** — 関係ない部位は保持したまま動く
- **足は静かに置く**
- **次のポーズに到達してから完全に収縮させる**
  （"arrive in the next position before you fully contract"）
- 構成要素は「ステップ・ピボット・リセット」。素人は転換で震える

> **最重要の実装上の含意:**
> 全ボーンを1本のイージングで同時に補間してはいけない。
> **① 足・腰の向き（移動・回転）が先行 → ② 腕が追従 → ③ 到達時に収縮**
> という位相差が必要。同時補間は「溶ける」動きになり演技として破綻する。

## 7. 現実装との差分（2026-09時点）

| 競技上の要件 | 現実装 |
|---|---|
| 規定＋フリースタイル＋シグネチャーの広い語彙 | 12ポーズ固定。アーチャー／ビクトリー／膝つき／クアッドストンプ等なし |
| 向きの変更は意図を伴う。正面↔背面は側面経由が原則 | ランダム抽選。90秒で13〜16回の大転換、合計1700〜2400° |
| 90秒で8〜12ポーズ | 24ポーズ |
| 決めは2〜3秒、つなぎは速く | 全ポーズ3.75秒固定（標準偏差0.000s） |
| 音のキメにポーズを**着地**させる | 拍でトランジション開始 → 128BPMで**1.71拍遅れて完成** |
| 入場後2〜3秒の「間」 | 0.0秒で強制的にポーズ |
| ドロップに最強ポーズを割り当てる | 楽曲構造解析なし。RMS16分割のみ |
| 小節・フレーズ単位 | 生のビート列を8拍ごとに間引くだけ |
| 脚のポーズ（前脚屈曲・かかと上げ・後方引き等） | 全ポーズで脚の指定ゼロ（常にTポーズ） |
| 手・指（拳／脇腹つまみ／組み手／手首掴み） | ハンドボーン未使用 |
| 足・腰先行 → 腕追従 → 到達後に収縮 | 全ボーン同時補間、固定0.8秒 |
| つなぎポーズを連結組織として使う | `category` は生成ロジックで未使用 |
| ステップ・ピボットの足さばき | 移動概念なし。足が滑って回る |

## 8. 未確定事項（この文書では決まらないこと）

- **各ポーズの正確な関節角度。** 文字情報では「前脚を曲げてかかとを上げる」までしか
  決まらず、度数は実機の Mixamo リグで目視調整するしかない
- 左右どちらを客席に向けるか（選手の得意側による。実装は左側面を既定とする）
- 選手個人の「最強ポーズ」（実装ではエネルギー最大点にモストマスキュラーか
  フロントダブルバイセップスを割り当てる）
- 表情・カリスマ（評価対象だが3Dモデルの表現範囲外）
- アクロバット要素（スコープ外）
